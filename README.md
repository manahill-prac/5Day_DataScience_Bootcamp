## Overview

DECODE is a 5-day intensive Data Science Bootcamp organized by the
Data Science team of GDGoC COMSATS Wah. The bootcamp follows the
complete Data Science pipeline from scratch — starting with Python
fundamentals and ending with a fully trained and evaluated Machine
Learning model.

Every session was designed for absolute beginners with no prior
Data Science experience required.

## What Was Covered

**Day 1 — Python Foundations**
- What is Data Science and the DS Pipeline
- Variables, Data Types, Lists, Tuples, Sets, Dictionaries
- Loops, Conditionals, Functions, f-strings

**Day 2 — Data Cleaning**
- NumPy & Pandas essentials
- Handling missing values and duplicates
- Fixing data types and inconsistencies
- Filtering, grouping and merging data

**Day 3 — EDA + Visualization**
- Exploratory Data Analysis mindset
- Matplotlib — anatomy of a plot
- Seaborn — Histplots, Boxplots, Heatmaps, Pairplots
- Writing meaningful insights from charts

**Day 4 — Feature Engineering**
- Feature Extraction from dates, numbers and text
- Encoding — Label, Ordinal, One-Hot
- Scaling — StandardScaler, MinMaxScaler
- Handling Imbalanced Data
- Train/Test Split and Data Leakage
- Sklearn Pipeline

**Day 5 — Model Building + Evaluation**
- Supervised vs Unsupervised vs Reinforcement Learning
- Linear Regression — theory and code
- Model Evaluation — MAE, RMSE, R²
- Overfitting, Underfitting, Bias-Variance Tradeoff
- Complete Pipeline with LinearRegression
